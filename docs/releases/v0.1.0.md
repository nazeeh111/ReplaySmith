# ReplaySmith v0.1.0

Show it once. Run it reliably.

ReplaySmith turns a demonstrated browser task or supported Chrome Recorder JSON into an inspectable, parameterized workflow. Run it locally, verify the intended outcome, and export the same behavior as Playwright JavaScript or an Agent Skill. No model or paid API is required.

## Included

- One-tab native Chromium recording with explicit text-outcome capture.
- Supported Chrome DevTools Recorder JSON import, automatic named inputs, and bounded workflow validation.
- CLI and local workflow studio for editing, replay, candidate evidence, and export.
- Deterministic semantic recovery with confidence/margin thresholds and explicit abstention.
- Consequential-action and form-submission permission guards; compatible recorded targets required.
- Navigation origin allowlist, blocked HTTP redirects and unexpected popup navigation.
- Playwright and Agent Skills exports embedding the runtime, scorer, inputs and outcome checks.
- Editable architecture/brand SVGs, genuine studio screenshots, silent launch demo and reproducible capture/composition source.

## Evidence

The local full suite passed 38 tests. Independent review reproduced and rechecked redirects, implicit form submissions, nested submit controls, interpolated keys, recording event order, and input preparation. A fresh consumer installation exercised the built CLI, browser installer, studio, standalone script and Agent Skill.

The published controlled benchmark ran 132 real Chromium trials. ReplaySmith completed 15/15 declared supported changed-page trials, explicitly abstained safely on 12/12 refusal trials, and took zero incorrect actions. Corrupted outcomes failed verification in all three repetitions. Independent selector, exact-semantic and simple-heuristic baselines and all per-trial evidence are in the repository. The suite is small, synthetic and developer-authored; it is not a claim of arbitrary-site reliability or broad competitor superiority. Timing overhead is reported, including the cost of guarded replay.

See repository CI for the Linux Node 22/24 matrix and the report for exact environment and artifact hashes.

## Install

```sh
npm install --global https://github.com/nazeeh111/ReplaySmith/releases/download/v0.1.0/replaysmith-0.1.0.tgz
replaysmith install-browser
replaysmith studio
```

Open the printed loopback URL. The example is a local form with fictional data and an exact saved-note check. The package is distributed through this GitHub release, not the npm registry. On Linux, Chromium may require OS dependencies; see the README.

## Boundaries

This first release targets one-origin, single-page workflows. Frames, multiple tabs, file transfers, drag/drop, arbitrary imported JavaScript, shadow-host selector chains and HTTP redirects are unsupported. Recovery does not infer arbitrary synonyms or understand every business action. Scores are heuristics, not probabilities. Review consequential actions explicitly. Origin checks constrain navigation, not all page network activity. Read SECURITY.md and docs/core-notes.md before private or consequential use.
